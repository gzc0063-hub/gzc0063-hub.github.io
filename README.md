# Gourav Chahal — Personal Website

Personal professional website for Gourav Chahal, Weed Science PhD student at Auburn University (PhD completing Summer 2027, available immediately after).

Live at: https://gzc0063-hub.github.io/ (later: agchahal.com)

## What is in this repo

- `index.html` — the whole site. Single self-contained file (inline CSS and JS, no build step). Sections: hero, About, Journey, Research, Projects, Publications, Contact.
- `images/portrait.jpg` — portrait photo used in the About section (conference portrait from CANVAS 2026). To swap it, replace this file; the page references it as `images/portrait.jpg`.
- `images/field-trial-1.jpg` (cotton field at sunset, Fairhope AL), `field-trial-2.jpg` (cotton picker, Fairhope AL), `field-trial-3.jpg` (freshly harvested peanut plant) — field photos shown in the Research section gallery. `images/sprayer.jpg` (backpack sprayer) and `images/presentation-canvas.jpg` (presenting the CPWC meta-analysis at CANVAS 2026) are also in the folder; the presentation photo is shown under the gallery.
- `assets/Gourav_Chahal_CV.pdf` — the CV the "Download CV" button points to.

## How it was built

Built with Claude (Fable 5.2) from a written brief, then checked and corrected by hand. Content rule for this site: every fact, number, title, link and date comes from the CV or the brief, verified against its source — nothing invented, nothing extrapolated. If a fact cannot be verified, it is left out.

Key numbers on the site (all verified):
- CPWC meta-analysis: 103 contrasts, 34 studies, 51 site-years, +59.9% (D109 refit, Nov 12, 2026)
- Forage herbicide meta-analysis: 13 studies, 185 contrasts, +17.9%
- 200+ growers reached through one-to-one communication and extension field days

## Editing

Edit `index.html` directly and commit. No build step, no dependencies except a Google Fonts link. Preview locally by opening `index.html` in a browser, or run any static server from this folder.
